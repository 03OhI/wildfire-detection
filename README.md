# 산불 영상의 화염·연기 검출

D-Fire로 전이학습한 AHE-YOLO11 모델을 FastAPI에 연결해 영상에서 화염(fire)과 연기(smoke)를 검출한 컴퓨터 비전 개인 프로젝트입니다. 브라우저에서 영상을 선택하면 프레임을 로컬 서버에 보내고, 서버가 반환한 검출 상자와 신뢰도를 원본 영상 위에 표시합니다.

## 로컬에서 실행하기

Windows PowerShell과 Python 3.13 기준입니다. 저장소 루트에서 실행합니다.

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

[영상 분석 화면](http://127.0.0.1:8000/ui/)에서 영상을 선택한 뒤 **분석 시작**을 누릅니다. 신뢰도 기준을 낮추면 더 많은 후보가 남습니다. NMS IoU 기준을 높이면 서로 겹치는 상자가 더 많이 남습니다. API 요청 형식과 응답은 [FastAPI 문서](http://127.0.0.1:8000/docs)에서 확인할 수 있습니다.

## 소스와 모델

- `app.py` — 원본 PyCharm 코드의 SSF·EMBC 모듈, 모델 로딩, 이미지 한 장을 받는 `POST /analyze`.
- `web/` — 영상 프레임 캡처, 임계값 조절, Canvas 시각화. FastAPI가 함께 제공하므로 별도의 Node.js 서버가 필요하지 않습니다.
- `weights/best.pt` — 당시 PyCharm 시연 코드가 불러온 학습 가중치입니다. 체크포인트에 기록된 학습 실행명은 `AHE_YOLO_Final100`, Ultralytics 버전은 `8.4.43`입니다. 커스텀 블록이 학습 당시의 `__main__` 이름으로 저장돼 있어 위의 `python app.py` 방식으로 실행합니다.

## 실험 기록과 다음 작업

같은 야간 산불 장면에서 20 epochs 모델은 오른쪽 화염 하나를 검출했고, 100 epochs 모델은 가운데와 아래쪽 화염까지 세 곳을 표시했습니다. 오른쪽 화염의 검출 신뢰도는 0.37에서 0.71로 바뀌었습니다. 한 장면의 비교이며 전체 평가셋에서의 정확도 차이는 별도 측정이 필요합니다.

시연에서 남은 문제는 연기 미검출이었습니다. 다음 실험은 실제 연기가 있는데 놓친 프레임과 안개만 있는 프레임을 나눠 모으고, 같은 조건에서 원본과 CLAHE 적용본의 연기 미검출·오탐을 비교하는 것입니다. 이 저장소의 실행 범위는 저장된 가중치를 이용한 추론과 영상 시연입니다.
